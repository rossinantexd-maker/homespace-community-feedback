# Геймлуп: идеи из комментов комьюнити

Здесь собрано то, что игроки сами писали про геймлуп и механики в комментариях под нашими роликами и постами (Bilibili, свежий срез 13.07.2026, и Xiaoheihe). Только голос комьюнити, без наших выводов.

## Как игроки критиковали старый луп (оценка, мировая карта, ресурсы за популярность)

- Снежный ком: у популярных всё растёт, низ рейтинга не листают, новичок не получает опыта.
- Ресурсы за лайки приведут к кольцам взаимной накрутки.
- Увидев красивый дом, игрок хочет его скопировать, а не соревноваться; принудительный лидерборд не мотивирует.
- Кайф оценки работает только у сильных строителей, слабых нечем удержать.
- Если признание и ресурсы завязаны на онлайн, одиночке ловить нечего.
- «Стройка плюс рейтинг плюс социалка» уже есть у других игр, нужна своя фишка.
