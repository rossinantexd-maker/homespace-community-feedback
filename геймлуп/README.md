# Геймлуп: идеи из комментов комьюнити

Здесь собраны интересные варианты геймлупа, которые предложили сами игроки в комментариях под нашими роликами. Собрано при разборе Bilibili (свежий скрейп 13.07.2026, 13 роликов, ~5700 комментов и веток). Мы сменили старый луп, поэтому и слушаем, чего люди реально хотят.

## Проблема старого лупа (который отбрасываем)

Старый цикл: строишь дом, игра ставит оценку, по оценке дом попадает на мировую карту, чем популярнее, тем больше гостей и ресурсов по популярности. Двигатель = рейтинг.

Почему не держит (по словам игроков):
- Снежный ком: у популярных всё растёт, низ рейтинга не листают, новичок не получает опыта.
- Ресурсы за лайки = кольца взаимонакрутки.
- Рейтинг не заходит культурно: наш игрок копирует чужой дом, а не соревнуется.
- Кайф оценки работает только у сильных строителей, слабых нечем удержать.
- Соло-игрок повисает, если признание завязано на онлайн.
- Звучит как то, что уже есть у VRChat / Minecraft / 房产达人 (нет фишки).

## Куда двигаться (общая формула из их идей)

Строишь и обставляешь дом, живёшь в нём через мини-игры (рыбалка, огород и готовка, питомцы, музыка), активности дают мягкую валюту и материалы, тратишь на новую мебель и стили, строишь дальше. Ресурсы ходят между игроками (обмен, помощь друг другу), признание через гостей и лайки-как-спасибо, а не через принудительный рейтинг. Сверху лёгкое 养成 в духе Sims, Stardew и Animal Crossing.
